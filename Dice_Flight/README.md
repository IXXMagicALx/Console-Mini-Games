# Dice_Flight

一款基于控制台的桌游，玩家与电脑 bot 竞赛谁先到达终点。经典"蛇与梯子"玩法的变体，包含多种影响移动的格子类型。

## 运行方式

或直接运行编译好的可执行文件 `bin\Debug\net10.0\Dice_Flight.exe

## 游戏玩法

- 从起点出发，谁先到达终点（格子80）谁获胜
- 轮流进行，玩家先手
- 按任意键掷骰子并移动
- 先到达终点者获胜

## 操作说明

- `W` - 在菜单中选择上一个选项
- `S` - 在菜单中选择下一个选项
- `J` - 确认/进入
- `任意键` - 游戏中掷骰子

## 格子类型

| 符号 | 名称 | 效果 |
|------|------|------|
| □ | 普通 | 无效果，正常移动 |
| ¤ | 陷阱 | 回到起点 |
| ∥ | 暂停 | 失去下一回合 |
| ● | 炸弹 | 倒退5格 |
| ∞ | 传送门 | 随机效果（见下方） |

## 传送门效果（出现概率10%）

- 20%：前进5格
- 20%：后退5格
- 40%：暂停一回合
- 20%：与对手交换位置

## 游戏界面

1. **开始界面** - 开始游戏或退出
2. **游戏界面** - 主要游戏区域，包含棋盘和操作提示
3. **结束界面** - 显示获胜者以及重新开始或退出的选项
