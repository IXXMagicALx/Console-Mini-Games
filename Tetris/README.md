# 俄罗斯方块 🧱

一个在控制台/终端中运行的**俄罗斯方块**游戏，使用 **C# .NET 10** 编写，纯控制台渲染，无任何外部依赖。

##游戏开始界面参考

```
┌────────────────────────────────────────────────┐
│                                                │
│                   俄罗斯方块                    │
│                                                │
│                [W/S] 上下选择                   │
│                [J]   确认                       │
│                                                │
│                   开始游戏                      │
│                   退出游戏                      │
└────────────────────────────────────────────────┘
```

## 功能特性

- 7 种标准四格方块
- 完整的旋转系统（除去正方形，每种方块 4 个旋转状态）
- 墙壁与方块碰撞检测
- 行消除与计分（每行 10 分）
- 下一个方块预览
- 开始画面 / 游戏结束画面
- 非阻塞后台键盘输入

## 操作方式

| 按键 | 功能 |
|------|------|
| `←` `→` | 逆时针 / 顺时针旋转 |
| `A` `D` | 向左 / 向右移动 |
| `S` | 加速下落 |
| `W` `S` | 菜单上下选择 |
| `J` | 菜单确认 |

## 环境要求

- [.NET 10.0 SDK] 或更高版本

## 构建与运行

```bash
# 克隆项目后进入目录
cd Tetris

# 构建
dotnet build

# 运行
dotnet run

# 发布版本
dotnet publish -c Release -o publish
```

也可直接运行编译后的可执行文件：

```bash
.\bin\Debug\net10.0\Tetris.exe
```

## 项目结构

```
Tetris/
├── Program.cs              # 入口点
├── Tetris.csproj           # 项目文件
├── Tetris.slnx             # 解决方案文件
├── GameBasic/              # 核心游戏框架
│   ├── Game.cs             # 游戏引擎、场景管理、主循环
│   ├── GameScene.cs        # 游戏主场景
│   ├── ISceneUpdate.cs     # 场景更新接口
│   ├── BeginOrEndBasic.cs  # 菜单基类
│   ├── BeginScene.cs       # 开始画面
│   └── EndScene.cs         # 游戏结束画面
└── GamePlay/               # 游戏机制
    ├── Position.cs         # 二维坐标结构
    ├── Object.cs           # 单元格对象与绘制
    ├── BlockInfo.cs        # 方块旋转数据定义
    ├── BlockManager.cs     # 方块生成、移动、旋转、碰撞
    ├── Map.cs              # 游戏地图、行消除、计分
    ├── HUD.cs              # 抬头显示
    ├── IDraw.cs            # 绘制接口
    └── InputThread.cs      # 后台键盘输入线程
```

## 技术栈

- **语言:** C# 13
- **框架:** .NET 10
- **依赖:** 无（纯 .NET BCL）
- **渲染:** 控制台光标定位 + 颜色
